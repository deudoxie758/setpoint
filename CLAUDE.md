# SetPoint — Volleyball Highlight Clip Library

Portfolio project. See `docs/superpowers/specs/2026-08-10-setpoint-design.md` for the full design spec.

## Durable instruction: keep DECISIONS.md updated

`DECISIONS.md` at the repo root is a running log of design and architecture decisions and the tradeoffs considered, kept so the developer can review it directly before job interviews.

**Whenever you make or discuss a non-trivial design/architecture decision while working on this project** — choice of library, data model change, API shape, auth approach, tradeoff between two approaches, etc. — **append an entry to `DECISIONS.md`** with: the decision, the alternatives considered, and the reasoning. Do this regardless of which Claude Code session you are, since the user works across multiple sessions on this project. Keep entries concise (a few sentences to a short paragraph) — this is a reference for interview prep, not a full ADR document.

Do not ask permission before appending an entry for a decision that was just made in the conversation — just do it, the same way you'd update code. Only skip it for truly trivial choices (variable naming, formatting) that wouldn't come up in an interview.
